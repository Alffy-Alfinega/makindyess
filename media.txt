GENERAL GUIDELINES
================================================================================

Directory Structure:
- /media/hero/         - Homepage hero section images
- /media/about/        - About page and leadership images
- /media/academics/    - Academic programs and facilities
- /media/admissions/   - Admissions-related imagery
- /media/news/         - News, events, and announcements
- /media/resources/    - Learning resources and facilities
- /media/contact/      - Campus location and building images

Supported Formats:
- IMAGES: JPG, PNG (JPG preferred for performance)
- VIDEOS: MP4, WebM
- Recommended: Compress images to <300KB using TinyPNG or similar

Naming Convention:
- Use lowercase with hyphens: hero-main.jpg, principal-portrait.jpg
- Include descriptive names for clarity
- Version numbers optional: image-name-v2.jpg

Accessibility Requirements:
- All images must have descriptive alt text in HTML
- Video content should include captions/subtitles where applicable
- Use semantic HTML with proper <img> and <figure> elements

Performance Optimization:
- Hero images: Max 1920x1080px (landscape)
- Portrait photos: Max 500x600px
- Thumbnails: Max 300x300px
- Use CSS max-width constraints to limit display size

================================================================================
CONTENT CREATION GUIDELINES
================================================================================

Photography Style:
- Professional, well-lit images (avoid shadows/poor lighting)
- Composition should be balanced and engaging
- Include people/students where possible (shows community)
- Avoid overly staged or artificial-looking photos
- Natural, authentic school environment preferred

Requirements for Success:
- Ensure proper consent/permissions for student photos
- Include diverse representation of students and staff
- High resolution originals (can be compressed for web)
- Consistent color temperature across images
- Image quality minimum: 72 DPI for web (300 DPI source recommended)

Quality Standards:
- No blurry, pixelated, or obviously Photoshopped images
- Consistent lighting and color balance
- Professional composition and framing
- Avoid copyrighted or stock-heavy appearance

================================================================================
UPLOADING INSTRUCTIONS
================================================================================

Step 1: Prepare Media Files
  - Optimize images to appropriate dimensions
  - Compress using TinyPNG (reduce file size)
  - Name files according to convention above
  - Place in appropriate /media/subdirectory/

Step 2: Update HTML References
  - Add <img> tags with src pointing to media files
  - Include meaningful alt text for accessibility
  - Use proper HTML5 <figure> and <figcaption> if captions needed

Step 3: Test
  - Check that images load correctly in browser
  - Verify alt text displays when images don't load
  - Test on mobile devices for proper responsive display

Step 4: Optimize
  - Use browser dev tools to check image load times
  - Consider lazy loading for off-screen images
  - Monitor page performance (target <3 second load)
